# 日迹

一个**本地优先**的个人日记程序，Windows 桌面版。

日记就是磁盘上的 Markdown 文件——一天一个 `.md`，程序只是它更好用的入口。
没有账号、没有云、不联网；把程序删掉，那些文件照样在，用记事本就能打开。

```
riji/2026/2026-10-08.md

---
date: 2026-10-08
mood: 平静
weather: 晴
tags:
  - 日常
---

今天写了一句。
```

## 主要功能

**写**

- **打开即写**：启动后光标直接落在今天的正文里
- **自动保存 + 草稿保护**：停止输入 0.9 秒落盘；编辑期间每 2 秒留一份草稿，崩溃重启会问你要不要恢复
- **绝不静默覆盖**：保存前确认磁盘上还是你读到的那一份，不是就把对方另存为冲突文件并明确提示
- 心情、天气、标签（预设 + 自由输入）、内联格式（`Ctrl+B` / `Ctrl+I` / `Ctrl+U`）
- 每日一问（120 条写作引子，同一天稳定不变）、时光机（随机翻到以前写的一篇）

**找**

- **全文搜索**：正文、标签、心情、天气、日期都能搜
- 筛选：按标签 / 心情 / 天气筛，条件一直显示在左边，一键清除
- 往年的今天：自动列出同月同日的历史日记
- **写作日历**：侧栏日历图标打开。月视图选日期，年视图是一年一张热力图（深浅按当天字数）；
  鼠标停上去看那一天，点一下就跳过去
- **黄历卡片**：鼠标停在某一栏约 0.65 秒，弹出干支、冲煞、宜忌（宜忌是传统历注，卡片上写明）

**护**

- **历史版本**：打开一天时、编辑过程中每隔一段时间自动留快照，可查看可恢复
- **回收站**：删除是软删除（移进 `.trash`，不抹字节），能恢复、能永久删除
- **备份**：关程序时自动做一份（一天至多一份，自动快照留最近 30 份，手动快照永不删）。
  位置要你自己设——**和日记在同一个盘时挡不住盘坏**，界面会如实告诉你这一点
- **每日提醒**：到点如果今天还没写，让 Windows 弹一条通知（进通知中心），点一下回到今天。
  默认关；可以指定星期几；程序不用常驻
- 单实例锁：用操作系统级文件锁保证只有一个实例在写日记目录

**顺手**

- **命令面板**：`Ctrl+K` 唤起，打几个字就能搜到界面上**每一个**动作，`↑↓` 选、`Enter` 执行。
  每行右边直接显示它的快捷键，所以它同时就是「快捷键总览」
- **本版更新**：升级后第一次启动弹一次，只讲版本、发布时间、新功能和修了什么
- 深色模式（跟随系统 / 浅色 / 深色）、编辑器排版（字号 / 行距 / 字重 / 行宽）、专注模式
- 一键导出成单个 Markdown 文件；日记位置可以改（只复制，从不移动）

## 下载和启动

到 [Releases](https://github.com/lkczy/riji/releases) 下最新的 `riji-x.y.z.zip`：

1. 解压到一个放着舒服的位置（比如 `D:\Apps\riji\`）
2. 双击里面的 `riji.exe`

**这个文件夹要一起带着**：`riji.exe` 运行时需要同目录的 `flutter_windows.dll` 和 `data\`——
不能只把 exe 拷出来。三个 VC++ 运行库（`msvcp140.dll` / `vcruntime140.dll` /
`vcruntime140_1.dll`）包里已经带了，不需要另外装，也不需要管理员权限。

要求：Windows 10 / 11，64 位。

## 第一次用

| | |
|---|---|
| 日记放哪 | 默认 `文档\riji`。想换：「⋮ → **日记存储位置**」 |
| 备份 | 「⋮ → **备份**」，设一个日记目录**之外**的位置 |
| 每日提醒 | 「⋮ → **每日提醒**」，默认关。打开会往系统里写一个计划任务和两个注册表项，关掉时一并删掉 |
| 换外观 | 标题栏的「外观」菜单（主题、字号 / 行距 / 字重 / 行宽） |
| 找功能 | `Ctrl+K`，或者右下角的「⋮」菜单 |

日记目录里除了按年份放的 `.md`，还有几个以 `.` 开头的目录（`.drafts/`、`.history/`、
`.trash/`）——它们是**本机的操作痕迹**，用同步工具时记得忽略掉。

## 从源码跑

```powershell
flutter run -d windows          # 开发
flutter test                    # 666 个测试
powershell -File tool\build_release.ps1   # 出发布版（内部强制 flutter clean + 图标审计）
```

产物在 `build\windows\x64\runner\Release\`；构建脚本会顺带在仓库根目录生成 `日迹.lnk` 启动器。

## 几个可能想问的

**为什么没有云同步？** 因为不需要自己写：日记目录丢给 Syncthing 或私有 git 就行，
它们都比一个自研同步服务可靠。见 [`docs/手机写作.md`](docs/手机写作.md)。

**为什么正文是纯文本而不是富文本？** 日记的价值在内容不在排版。所见即所得编辑器会带来
格式转换、粘贴污染、导出失真一整类问题，而收益接近于零。

**为什么零插件（连 `path_provider` 都不用）？** Flutter 为插件建符号链接要求 Windows
开启开发者模式，而开开发者模式需要管理员权限——只为定位一个目录付这个代价不值得。
每日提醒也一样：靠命令行调 PowerShell 的计划任务和系统通知，没引入任何插件。
